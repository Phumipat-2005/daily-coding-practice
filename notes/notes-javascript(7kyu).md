1# 📝 บันทึกสรุปพื้นฐาน JavaScript (7 kyu)

### 1. การตรวจสอบและค้นหาข้อความด้วย Regular Expression (RegEx)
* **การจับคู่รูปแบบด้วย `.match()`:**
  * โครงสร้าง: `str.match(/pattern/flags)`
  * ตัวอย่างค้นหาสระ: `str.match(/[aeiou]/g)`
    * เครื่องหมายก้ามปู `[...]`: ระบุกลุ่มตัวอักษรที่ต้องการค้นหา (Character Set)
    * แฟลก `g` (Global Flag): สั่งให้ค้นหาครบทุกจุดทั่วทั้งข้อความ ไม่หยุดแค่ตัวแรกที่พบ
  * คืนค่าผลลัพธ์ออกมาเป็น **Array ของตัวอักษรที่พบ**
* **เทคนิค Safe Navigation ป้องกันแอปพัง (`|| []`):**
  * ถ้าค้นหาไม่พบเลยแม้แต่ตัวเดียว คำสั่ง `.match()` จะคืนค่าเป็น **`null`**
  * การเรียก `.length` ต่อท้าย `null` จะทำให้เกิด TypeError (`Cannot read properties of null`) ทันที
  * **วิธีแก้:** ดักด้วย Fallback Empty Array เสมอ เช่น:
    ```javascript
    const count = (str.match(/[aeiou]/g) || []).length;
    ```

### 2. การตรวจสอบการมีอยู่ของข้อมูล (String Inspection)
* **คำสั่ง `str.includes()`:**
  * โครงสร้าง: `targetString.includes(searchElement)`
  * ทำหน้าที่ตรวจว่ามีตัวอักษรหรือคำที่ค้นหาอยู่ในข้อความหรือไม่ โดยคืนค่าเป็น Boolean (`true` / `false`)
  * นิยมนำมาใช้เป็นเกณฑ์ตรวจสอบเงื่อนไข เช่น `"aeiou".includes(char)`

---

### 3. การนับจำนวนด้วยการแปลงสตริงเป็น Array (Functional Approach)
* **โครงสร้าง `.split('')` ร่วมกับ `.filter()`:**
  * หั่นข้อความให้กลายเป็น Array ของตัวอักษรเดี่ยวๆ ด้วย `.split('')`
  * ใช้ `.filter()` กรองเอาเฉพาะตัวอักษรที่ตรงเงื่อนไข
  * ดึงจำนวนผลลัพธ์ด้วย `.length` ได้ทันที:
    ```javascript
    str.split('').filter(char => "aeiou".includes(char)).length;
    ```

### 4. ตารางสรุป Methods & RegEx (7 kyu Cheat Sheet Part 1)

| คำสั่ง / ไวยากรณ์ | หน้าที่ | ตัวอย่างการใช้งาน | ผลลัพธ์ |
|---|---|---|---|
| `/[aeiou]/g` | RegEx ค้นหาสระทุกตัวในข้อความ | `"abracadabra".match(/[aeiou]/g)` | `['a', 'a', 'a', 'a', 'a']` |
| `str.match() \|\| []` | ดึงข้อมูลที่ตรง Pattern พร้อมป้องกัน Error กรณีหาไม่เจอ | `("sky".match(/[aeiou]/g) \|\| []).length` | `0` |
| `str.includes(char)` | เช็คว่ามีตัวอักษรในสตริงหรือไม่ | `'aeiou'.includes('a')` | `true` |
| `str.split('')` | แปลง String เป็น Array ทีละตัวอักษร | `'cat'.split('')` | `['c', 'a', 't']` |

### 5. การค้นหาและแทนที่ข้อความด้วย `.replace()` และ RegEx
* **การค้นหาและแทนที่ด้วย `.replace()`:**
  * โครงสร้าง: `str.replace(pattern, replacement)`
  * เทคนิคการลบข้อมูล (Deletion by Replacement): กำหนดค่าแทนที่เป็นสตริงว่าง `''` ตัวอักษรที่ตรงเงื่อนไขจะถูกตัดทิ้งทันที
  * องค์ประกอบของ RegEx `/[aeiou]/gi`:
    * เครื่องหมายทับ `/[...]/`: Delimiter ระบุสูตรค้นหาแบบ RegEx
    * เครื่องหมายก้ามปู `[...]`: Character Set ค้นหาตัวอักษรใดตัวหนึ่งในกลุ่ม
    * แฟลก `g` (Global): ค้นหาและแทนที่ทุกตำแหน่งทั่วทั้งประโยค ไม่หยุดแค่ตัวแรกที่พบ
    * แฟลก `i` (Case-Insensitive): ตรวจจับโดยไม่แยกตัวพิมพ์เล็กหรือตัวพิมพ์ใหญ่ (ครอบคลุมทั้ง `a-z` และ `A-Z`)
  * ตัวอย่างโค้ด:
    ```javascript
    const disemvowel = str => str.replace(/[aeiou]/gi, '');
    ```

### 6. ความไม่เปลี่ยนแปลงของข้อความ (String Immutability)
* **คุณสมบัติ String Immutability:**
  * ข้อความ (String) ใน JavaScript เป็นประเภท Immutable ไม่สามารถแก้ไขเปลี่ยนแปลงค่าเดิมในหน่วยความจำได้
* **พฤติกรรมของ Non-mutating Methods:**
  * คำสั่งเช่น `.split()`, `.filter()`, `.join()` ไม่แก้ไขตัวแปรต้นทาง แต่จะประมวลผลแล้วส่งมอบเป็น **"ก้อนข้อมูลใหม่"** เสมอ
  * หากไม่สั่ง `return` ก้อนผลลัพธ์นั้นออกไปตรงๆ หรือไม่มีตัวแปรมารับ ค่าที่ประมวลผลเสร็จแล้วจะสลายหายไป และตัวแปรเดิมจะยังคงมีค่าเท่าเดิม

### 7. โครงสร้างลูปและการสะสมข้อความ (Accumulator Pattern & Best Practices)
* **การใช้ตัวสะสมข้อความ (Accumulator Pattern):**
  * ประกาศ `let result = '';` เป็นสตริงว่างเพื่อรอรับตัวอักษรที่ผ่านเงื่อนไขมาต่อท้ายทีละตัวด้วย `result += char;`
* **การตรวจสอบด้วย `!set.includes(char)`:**
  * เครื่องหมาย `!` (NOT Operator) สลับค่าความจริง เพื่อคัดเลือกเฉพาะตัวอักษรที่ **ไม่ได้** อยู่ในกลุ่มสระ
  * ฟังก์ชัน `.includes(char)` ทำหน้าที่ตรวจเช็คว่ามีตัวอักษรนั้นอยู่ในชุดอ้างอิงหรือไม่ (คืนค่า `true` / `false`)
* **กฎหลีกเลี่ยงการเขียนทับ Parameter (`no-param-reassign`):**
  * ไม่ควรเขียนค่าทับตัวแปร Parameter เช่น `str = str.split()...` เพื่อป้องกัน Side Effects ตามมาตรฐานสากล (ESLint)
  * แนวทางที่ถูกต้อง: สั่ง `return` ผลลัพธ์จากการต่อ Method Chain ออกไปโดยตรง

| คำสั่ง / ไวยากรณ์ | หน้าที่ | ตัวอย่างการใช้งาน | ผลลัพธ์ |
|---|---|---|---|
| `str.replace(reg, '')` | ลบข้อความส่วนที่ตรงกับ Pattern ออก | `"This website".replace(/[aeiou]/gi, '')` | `"Ths wbst"` |
| แฟลก `gi` | ค้นหาทั่วทั้งประโยค + ไม่สนพิมพ์เล็ก/ใหญ่ | `"LOL".replace(/[o]/gi, '')` | `"LL"` |
| `[...str]` | กระจายตัวอักษรลง Array (ทางเลือกแทน `.split('')`) | `[..."abc"]` | `['a', 'b', 'c']` |
| `!set.includes(char)` | ตรวจสอบว่าตัวอักษรไม่อยู่ในกลุ่มที่กำหนด | `!'aeiou'.includes('b')` | `true` |

### 9. การแปลงสตริงตัวเลขและการหาค่าสุดขีด (Min/Max Operations)
* **การหั่นข้อความด้วยช่องว่าง (`.split(' ')`):**
  * สั่งหั่นโดยเว้นวรรคข้างในเครื่องหมายคำพูด `' '` เพื่อแยกคำหรือชุดตัวเลขที่คั่นด้วย Space
  * *ข้อควรระวัง:* แตกต่างจาก `.split('')` (สตริงติดกัน) ที่ใช้สับอักษรทีละตัว
* **การหาค่าน้อยสุด/มากสุดร่วมกับ Spread Operator (`...`):**
  * โครงสร้าง: `Math.max(...arr)` และ `Math.min(...arr)`
  * ตัวดำเนินการ Spread Operator `...` ทำหน้าที่กระจายสมาชิกใน Array ออกมาเป็นรายการเดี่ยวๆ เพื่อป้อนเข้าฟังก์ชัน `Math`
  * JavaScript จะทำ Type Coercion แปลงสตริงตัวเลข เช่น `"42"` ให้กลายเป็น Number โดยอัตโนมัติขณะคำนวณ
* **ตัวอย่างโค้ด:**
  ```javascript
  function highAndLow(numbers) {
    const arr = numbers.split(' ');
    return `${Math.max(...arr)} ${Math.min(...arr)}`;
  }
  ```

### 10. การจัดการข้อความด้วย Template Literals (String Interpolation)
* **องค์ประกอบของ Template Literals:**
  * เครื่องหมายแบ็กทิก (`` ` ``): ครอบหัวท้ายข้อความเพื่อเปิดโหมดแทรกตัวแปรและรองรับการขึ้นบรรทัดใหม่อิสระ
  * เครื่องหมายดอลลาร์และปีกกา (`${...}`): กล่องประมวลผลคำสั่ง JavaScript โดยจะดึงค่าของตัวแปรหรือผลลัพธ์จากการคำนวณมาแปลงเป็นข้อความแปะแทนที่ลงในตำแหน่งนั้น
* **ข้อดีเมื่อเทียบกับการเชื่อมข้อความด้วยเครื่องหมายบวก (`+`):**
  * ลดความผิดพลาดเรื่องการลืมเว้นวรรค เช่น `` `${max}${min}` `` เทียบกับ `max + " " + min`
  * โค้ดสะอาด อ่านง่าย และตรงตามหลักมาตรฐานสากล

|---|---|---|---|
| `str.split(' ')` | แยกข้อความออกเป็น Array ตามจุดเว้นวรรค | `"1 2 3".split(' ')` | `["1", "2", "3"]` |
