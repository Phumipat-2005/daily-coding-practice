# 📝 บันทึกสรุปพื้นฐาน JavaScript (8 kyu)

---

### 1. Arrow Function (`=>`) และกฎการ Return
* **รูปแบบการเขียน:** `const functionName = (param) => ผลลัพธ์;` *(ห้ามใส่คำว่า `function` ปนกับ `=>`)*
* **วงเล็บ `()` ของ Parameter:**
  * มีตัวแปรเดียว: ละวงเล็บได้ เช่น `num => -num`
  * มี 0 ตัว หรือตั้งแต่ 2 ตัวขึ้นไป: ต้องใส่วงเล็บเสมอ เช่น `() => ...` หรือ `(a, b) => a + b`
* **การคืนค่า (Return):**
  * **ไม่มีปีกกา `{ }`:** คืนค่าให้อัตโนมัติ (Implicit Return)
  * **มีปีกกา `{ }`:** ต้องพิมพ์คำสั่ง `return` เสมอ มิฉะนั้นค่าที่ได้จะเป็น `undefined`

---

### 2. Ternary Operator (`? :`)
* **โครงสร้าง:** `เงื่อนไข ? ทำเมื่อเป็นจริง : ทำเมื่อเป็นเท็จ`
* **ตัวอย่าง:** `number % 2 === 0 ? "Even" : "Odd"`
* ใช้งานแทน `if...else` สำหรับการคืนค่าบรรทัดเดียว และใช้บ่อยมากใน React JSX

---

### 3. เครื่องหมายคำพูด: ข้อความ (String) vs ตัวแปร (Variable)
* **มีเครื่องหมายคำพูด (`""` หรือ `''`):** คือข้อความ String ตรงตัว เช่น `"Even"`, `"Odd"`
* **ไม่มีเครื่องหมายคำพูด:** คือชื่อตัวแปรหรือตัวเลข เช่น `num`, `-num`, `42`
* *ข้อควรระวัง:* ถ้าเขียน `"-num"` ระบบจะมองว่าเป็นตัวหนังสือคำว่า "-num" ไม่ใช่ค่าติดลบของตัวแปร

---

### 4. รวม Methods และฟังก์ชันพื้นฐานที่ใช้บ่อย

| คำสั่ง / Method | หน้าที่ | ตัวอย่างการใช้งาน | ผลลัพธ์ |
|---|---|---|---|
| `String(x)` | แปลงค่าเป็นข้อความ | `String(123)` | `"123"` |
| `Math.abs(x)` | แปลงเป็นค่าบวกเสมอ (Absolute) | `Math.abs(-5)` | `5` |
| `.split('')` | หั่น String ออกเป็น Array ทีละตัวอักษร | `"abc".split('')` | `['a', 'b', 'c']` |
| `.reverse()` | สลับลำดับข้อมูลใน Array จากหลังมาหน้า | `[1, 2, 3].reverse()` | `[3, 2, 1]` |
| `.join('')` | รวมข้อมูลใน Array กลับเป็น String ก้อนเดียว | `['a', 'b'].join('')` | `"ab"` |

### 5. เทคนิคการจัดการข้อความ (String Operations)
* **การทำซ้ำข้อความ (`.repeat()`):**
  * `s.repeat(n)` ➔ ทำซ้ำข้อความ `s` เป็นจำนวน `n` ครั้ง
* **การตัดข้อความด้วยตำแหน่ง Index (`.slice()`):**
  * โครงสร้าง: `str.slice(start, end)` (ตัดตั้งแต่ `start` ถึงก่อน `end`)
  * การตัดหัวตัดท้าย: `str.slice(1, -1)` (เริ่ม index 1 ตัดตัวแรกทิ้ง และ `-1` ตัดตัวสุดท้ายทิ้ง)
  * *ข้อดี:* ถ้าข้อความยาว $\le 2$ ตัวอักษร ระบบจะคืนค่า `''` (สตริงว่าง) ให้อัตโนมัติโดยไม่เกิด Error
* **Template Literals (Backtick `` ` ``):**
  * ใช้ครอบข้อความเพื่อแทรกตัวแปรหรือการคำนวณผ่าน `${...}` เช่น `` `Hello ${name}` ``
  * เคาะขึ้นบรรทัดใหม่ได้อิสระโดยไม่ต้องใส่ `\n`

---

### 6. การจัดการข้อมูลใน Array และการวนลูป
* **ลูป `for...of` (วนหยิบข้อมูลทีละตัว):**
  * รูปแบบ: `for (const item of array) { ... }`
  * ลูปจะหมุนรอบตามจำนวนสมาชิกใน Array โดยอัตโนมัติ โดยตัวแปรหน้า `of` จะเก็บค่า Element แต่ละตัวตามลำดับ
* **`.filter()` (ตัวกรองข้อมูล):**
  * คัดเลือกเฉพาะสมาชิกที่เงื่อนไขเป็นจริง (`true`) ออกมาเป็น Array ใหม่ เช่น `arr.filter(num => num > 0)`
* **`.reduce()` (การยุบรวมผลลัพธ์):**
  * โครงสร้าง: `arr.reduce((acc, cur) => acc + cur, initialValue)`
  * ตัวเลขท้ายสุดคือ **ค่าเริ่มต้น (Initial Value)** ใส่เพื่อป้องกัน Error เวลาเจอ Array ว่าง

---

### 7. รูปแบบตรรกะและการเขียนระดับสูง (Logic Patterns)
* **Object Lookup (ค้นหาค่าผ่านกุญแจ):**
  * รูปแบบ: `({ true: 'Yes', false: 'No' })[bool]`
  * ต้องใช้เครื่องหมายก้ามปู `[ตัวแปร]` เพื่อนำค่าในตัวแปรไปเปิดหา Key (ถ้าใช้ `.ตัวแปร` มันจะค้นหาคำว่า `"ตัวแปร"` ตรงๆ)
* **Guard Clause / Early Return:**
  * เมื่อสั่ง `return` โปรแกรมจะหยุดทำงานและดีดตัวออกจากฟังก์ชันทันที จึงไม่จำเป็นต้องต่อ `else` เสมอไป
* **Additive Inverse (คณิตศาสตร์กลับขั้ว):**
  * ใส่เครื่องหมายลบ `-` หน้าตัวแปรตัวเลขตรงๆ เช่น `-number` จะสลับบวกเป็นลบ และลบเป็นบวกโดยอัตโนมัติ

### 8. ตารางสรุป Methods เพิ่มเติม (Cheat Sheet Part 2)

| คำสั่ง / Method | หน้าที่ | ตัวอย่างการใช้งาน | ผลลัพธ์ |
|---|---|---|---|
| `str.repeat(n)` | ทำซ้ำข้อความตามจำนวน $n$ | `'Hi'.repeat(3)` | `'HiHiHi'` |
| `str.slice(start, end)` | ตัดชิ้นส่วนข้อความตาม index | `'hello'.slice(1, -1)` | `'ell'` |
| `arr.filter(fn)` | กรองข้อมูลใน Array ตามเงื่อนไข | `[1, -2, 3].filter(x => x > 0)` | `[1, 3]` |
| `arr.reduce(fn, init)` | วนรวมผลลัพธ์สมาชิกทุกตัวใน Array | `[1, 2, 3].reduce((a, b) => a + b, 0)` | `6` |
| `-number` | กลับขั้วตัวเลข (บวก $\leftrightarrow$ ลบ) | `-(-5)` หรือ `-(5)` | `5` หรือ `-5` |
