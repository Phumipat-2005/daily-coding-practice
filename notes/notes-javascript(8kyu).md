### 1. Arrow Function (`=>`) และกฎการ Return
* **รูปแบบการเขียน:** `const functionName = (param) => ผลลัพธ์;` *(ห้ามใส่คำว่า `function` ปนกับ `=>`)*
* **วงเล็บ `()` ของ Parameter:**
  * มีตัวแปรเดียว: ละวงเล็บได้ เช่น `num => -num`
  * มี 0 ตัว หรือตั้งแต่ 2 ตัวขึ้นไป: ต้องใส่วงเล็บเสมอ เช่น `() => ...` หรือ `(a, b) => a + b`
* **การคืนค่า (Return):**
  * **ไม่มีปีกกา `{ }`:** คืนค่าให้อัตโนมัติ (Implicit Return)
  * **มีปีกกา `{ }`:** ต้องพิมพ์คำสั่ง `return` เสมอ มิฉะนั้นค่าที่ได้จะเป็น `undefined`

---

### 2. Ternary Operator (`? :`)
* **โครงสร้าง:** `เงื่อนไข ? ทำเมื่อเป็นจริง : ทำเมื่อเป็นเท็จ`
* **ตัวอย่าง:** `number % 2 === 0 ? "Even" : "Odd"`
* ใช้งานแทน `if...else` สำหรับการคืนค่าบรรทัดเดียว และใช้บ่อยมากใน React JSX

---

### 3. เครื่องหมายคำพูด: ข้อความ (String) vs ตัวแปร (Variable)
* **มีเครื่องหมายคำพูด (`""` หรือ `''`):** คือข้อความ String ตรงตัว เช่น `"Even"`, `"Odd"`
* **ไม่มีเครื่องหมายคำพูด:** คือชื่อตัวแปรหรือตัวเลข เช่น `num`, `-num`, `42`
* *ข้อควรระวัง:* ถ้าเขียน `"-num"` ระบบจะมองว่าเป็นตัวหนังสือคำว่า "-num" ไม่ใช่ค่าติดลบของตัวแปร

### 4. รวม Methods และฟังก์ชันพื้นฐานที่ใช้บ่อย

| คำสั่ง / Method | หน้าที่ | ตัวอย่างการใช้งาน | ผลลัพธ์ |
|---|---|---|---|
| `String(x)` | แปลงค่าเป็นข้อความ | `String(123)` | `"123"` |
| `Math.abs(x)` | แปลงเป็นค่าบวกเสมอ (Absolute) | `Math.abs(-5)` | `5` |
| `.split('')` | หั่น String ออกเป็น Array ทีละตัวอักษร | `"abc".split('')` | `['a', 'b', 'c']` |
| `.reverse()` | สลับลำดับข้อมูลใน Array จากหลังมาหน้า | `[1, 2, 3].reverse()` | `[3, 2, 1]` |
| `.join('')` | รวมข้อมูลใน Array กลับเป็น String ก้อนเดียว | `['a', 'b'].join('')` | `"ab"` |
